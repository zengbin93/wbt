# 日收益指标的退化行为

`daily_performance` 为回测 stats、多空拆分、分段统计及滚动指标共用的计算核。
收益使用单利累计；累计收益为零不代表没有波动或回撤，恒定非零收益也必须保留收益和胜率。
字段名称、数值类型和四位小数展示精度保持原契约。

## 约定

- 空输入及真正的全零输入（每个值均为 0）保留默认结果：所有数值字段为 0，回归年度回报率为 None。
- 对其他输入逐项计算。夏普的标准差分母小于 `f64::EPSILON` 时，夏普约定为 0；这不是无收益的含义。
- 回撤风险为最大回撤除以**未舍入**的年化波动率，再舍入结果。标准差或年化波动率小于 `f64::EPSILON` 时，该比率约定为 0；恒定负收益的最大回撤仍保留。此时比率 0 不表示没有回撤。
- 最大回撤小于 `f64::EPSILON` 时，卡玛按年化收益的符号取 +10、-10 或 0；有回撤时按年化收益/最大回撤计算，仍限制到 [-10, 20]。正收益无回撤的 +10 沿用原约定。
- 标准差使用总体口径（ddof=0）。下行波动率使用负收益子集的总体标准差；没有负收益、只有一个负收益或负收益恒定时为 0。
- 至少两个样本才可计算累计收益的回归斜率。单样本的回归年度回报率为 None；恒定非零日收益的斜率正常计算。
- 回撤与 `top_drawdowns`、结果曲线一致：历史高点包含 **t=0 的零累计收益本金基线**，不额外添加观测日期。因此单个 -1% 收益样本的最大回撤为 1%。
- 日胜率沿用非负收益日计胜的口径（全零输入按上述默认约定）；无亏损时日盈亏比沿用 5，日赢面仍按既有公式计算，可能大于 1。盈亏平衡点是排序后累计收益首次严格为正所需样本的占比，无法达到时为 1。新高占比包括持平历史高点的日期，首个累计点仅在不低于本金基线时计入；新高间隔统计连续严格水下天数。
