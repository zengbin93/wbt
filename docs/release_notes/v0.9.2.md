# WBT 0.9.2

## 发布范围

本次仅发布公共 PyPI 的 Python 包，不发布 Crates.io、不升级用户环境。
0.9.2 为报告渲染修复与内部展示优化：公共导出 API、参数、返回类型、Rust 回测计算、依赖下限及 Python 最低版本未变，按项目 SemVer 决策表使用 PATCH。

## 变化

- 在 HtmlReportBuilder 组合边界，将受支持的五类单 Plotly Table 片段转为原生 HTML 表格，避免表格高度裁切，并保留原始数据、格式及其他图表。
- 改善策略判定局部展示：图形刻度、折叠原文详情及保守阈值识别；不重算指标、不生成新的策略判断。
- 正式线上发布增加成品元数据、安装、导入及相关回归门禁；任何新增加载、校验或测试失败均阻止 PyPI 上传。

## 已知问题和边界

- **保留原 stripping 配置。** Rust 1.97.1 下已观察到 macOS Mach-O string pool 未对齐；同 SHA 预检包在 macOS 15.7.9/26.6.2 ARM64 可加载，在本机 macOS 27.0.1 被拒绝。用户已知情选择不实施关闭 stripping，不能声称问题已解决或全平台兼容。macOS 27 用户可暂保留已验证可加载的旧版；不要安装此前失败取证包。
- 已有 HTML 不会自动变化；发布后的安装升级和报告重新生成仍是独立动作。本次不替用户执行升级。
- 自定义格式、隐藏状态、模板及不能忠实转换的 Plotly 输入继续保守回退，可能保留窄屏限制；绕过 builder 的外部生成器不自动受益。
- 浏览器已有 Chromium 验证；Firefox/Safari、真实触屏、辅助技术未实测。

初步未发现新的高/中级阻断项；已知 macOS 27 加载风险保留并由用户选择不修复。此快审不冒充独立 PR 审核，最终审核人仍须验证范围、发现及处置并在 PR 留痕后才可合并。
