# wbt v0.8.2

> Release date: TBD
> Crate tag: `crate-v0.8.2` · Python tag: `v0.8.2`

## Summary

PATCH release that restores reliable sizing for initially visible Plotly charts in
HTML backtest reports. Public API signatures and exported symbols are unchanged.

## Fixed

- 首屏和每个图表区的活动标签页现在都会在 DOM ready 与 `window.load` 后触发
  Plotly resize，避免图表首次打开时尺寸为零或布局错误。
- Plotly 尚未加载的报告页会安全跳过 resize，不再因 `Plotly` 未定义而抛出
  JavaScript 异常。

## Compatibility

- 无公共 API、类型签名、输出字段或数值口径变更。

## Tests

  所有初始活动标签页及 Plotly 未加载保护。
