# v0.9.1

> Release date: 2026-09-10
> Crate tag: `crate-v0.9.1` · Python tag: `v0.9.1`

## Summary

PATCH release：修复 v0.9.0 引入的 JSON/MessagePack 默认导出回归（SKZ-753），并同步修正 wire-schema 文档示例（SKZ-755）。

## Changes

- **fix**：`to_msgpack` / `to_json` / `dump_msgpack` / `dump_json` 的 `full` 参数默认值恢复为 `True`（`BacktestResult` 方法与 `wbt.serialization` 模块函数共 8 个入口）。v0.9.0 曾将该默认值改为 `False`，相对 v0.8.x 构成默认行为回归；本次恢复 v0.8.x 语义——默认导出包含全部审核字段（`verdict` / `verdict_recent` / `drawdowns` / `key_trades` / `yearly_returns` / `rolling` / `segment_comparison` / `curves_voladj`），仅需基础字段时显式传 `full=False`。`BacktestResult.to_dict()` 保持默认 `full=False`（v0.8.x 原有行为）。wire 格式仍为 v2，读取端对 full=True/False 双向兼容。（#52）
- **docs**：`docs/d04-wire-schema.md` envelope 写出示例的 `full` 标志与「默认完整导出」语义对齐；`docs/release_check.md` 更新流程基线（本地不跑测试门禁，质量验证由 GitHub CI 承担）。（#53）

## Notes for downstream

- 已按 v0.9.0 迁移指引显式传 `full=True` 的调用方升级后行为不变。
- 依赖 v0.9.0「默认精简导出」行为的下游（严格 schema 校验、落盘体积敏感的管道）升级后默认 payload 将重新包含 8 个审核字段；需要精简时请显式传 `full=False`。

## Pre-release review（§4）

- 范围：`v0.9.0..HEAD` 全量 diff（7 文件）+ 受影响模块全文（`python/wbt/result.py`、`python/wbt/serialization.py`、`python/tests/test_wire_schema.py`）+ 调用方穷举（`__init__.py` re-export 链、quick_start.ipynb、对比脚本）+ 冷读对照 `python/wbt/backtest.py`；交叉核对 v0.8.2 历史签名与 Rust 读取端 `src/core/backtest_result_wire.rs`。
