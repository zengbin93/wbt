# 策略判定说明的局部候选

本候选从已合并 main `ff38e79` 开始，不包含此前未提交整页候选的全局样式改动。
只处理报告组合边界中已有的 history/recent 判定说明：先使用原富文本清洗，再将
原标题/状态、原近期字段和原判定理由分别呈现。字段值直接使用已格式化的原字符串，
不读取额外数据、不重算、不生成新结论。其他表格、年度表格、图表、导航、指标与主题
按 main 保持不变；局部高度变化会使其后的策略表格自然顺延。

默认展示 history/recent 的原判定状态图形、两项零基线收益图和两项同尺度回撤图。
收益坐标固定为 -100% 至 +100%，回撤为 0 至 100%；这是刻度，不是评分、完成度或达标比例。
未知值或超出该显示尺度的值不绘制，完整原字符串仍保留在详情，不做截断或推断。
原生 `details/summary` 默认折叠，支持键盘 Space/Enter，完整原文（包括全部八个近期字段）不删改。
唯一支持的阈值标记来自原近期理由的严格模式
`alpha_max_drawdown=数值 ≥ threshold 数值`，要求指标按原两位百分比格式与字段值一致，
阈值在 0 至 1 之间；否则不画阈值。其他理由、阈值与判断仍完整保留在详情中，不推断。
识别只接受 ASCII 十进制小数（整数部分、小数点及小数部分均完整），字段前仅允许
起始位置或括号/逗号/分号分隔，数值后仅允许说明结束、右括号或分号。
字段名前缀、指数/字母后缀、数字截断及重复赋值（包括冲突、相同或格式不支持的第二次赋值）
均不绘制阈值线和标签，详情原文保持不变。保守拒绝并非解释或重算其他数字格式。
只有符合原内置 history/recent 标题结构且状态为原“可用/不可用”的说明才使用组件，未知结构回退原段落。
已有格式/隐藏/模板等不支持的 Plotly 输入继续由原兼容保护回退，不会强行原生化。

在候选的 `python` 目录执行（Python 需具备仓库测试依赖及 Playwright）：

```sh
python tests/manual/prepare_report_browser_assets.py /path/to/assets
WBT_BASELINE_SOURCE=/path/to/clean-ff38e79-checkout \
WBT_BROWSER_ASSETS=/path/to/assets \
WBT_BROWSER_ARTIFACTS=/path/to/artifacts \
WBT_BROWSER_EXECUTABLE=/path/to/chromium \
python -m pytest -q tests/test_verdict_component.py tests/test_report_plotly_boundary.py
```

局部原文详情展开后的真实文字边界、SVG 数据坐标和阈值位置、原生折叠键盘操作和可见焦点；区域外的
头部/指标/导航样式及坐标、全部表格内容和样式、其他图表数据/配置/坐标保持一致。
