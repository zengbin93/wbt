# D01：回撤包含初始本金

累计收益仍采用单利求和；运行峰值改为 `max(0, 历史累计收益)`，将 t=0 本金纳入风险衡量。`[-10%, +2%, +1%]` 的绝对收益为 -7%、最大回撤为 10%、卡玛为 -10（现有下限）。绩效、新高占比/间隔、回撤明细、原始与波动率归一曲线采用同一基线，滚动/分段计算各自从零本金开始。

兼容性：这是业务口径调整，首日亏损或未回本序列的回撤、卡玛和新高指标可能改变。没有新增日期或收益样本；t=0 无真实时间戳，因此初始回撤明细的开始日期仍标为首个观测日，天数仍为观测日期之差。空输入、累计收益为零、零波动序列返回默认指标的历史规则不在本次调整范围内。
